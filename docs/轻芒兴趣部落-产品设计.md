# 轻芒 · 兴趣部落 —— 产品设计文档（完整版）

**项目名称**：轻芒 · 兴趣部落（暂代）
**项目定位**：一个氛围轻松、低压迫感、实时在线的兴趣博客社区。面向普通用户，强调"沉浸式浏览"与"即时互动"。

## 一、 整体风格与设计基调

- **视觉风格**：采用**毛玻璃质感**与**大圆角**结合，背景使用柔和的渐变色或微动效模糊背景，营造呼吸感。
- **色彩体系**：主色调为低饱和度的中性色（奶白、浅灰）搭配品牌点缀色（暖橘或薄荷绿）。文字层级清晰，减少视觉噪音。
- **暗色模式**：全局支持一键切换深色/浅色主题，切换动画需流畅自然（颜色渐变过渡）。
- **交互反馈**：所有可点击元素需包含 Hover 悬浮微动效（上浮、阴影变化）和 Click 触感反馈（水波纹或轻触缩放）。

## 二、 全局布局与框架

采用经典的"左导航 + 右内容"双栏结构：

### 1. 顶部导航栏（全局固定）
- **左侧**：展示应用 Logo 与名称（点击返回主页）。
- **中部**：全局搜索框（占位符："搜兴趣、找好友、看热门..."），支持 Enter 触发全站模糊搜索。
- **右侧（从左至右）**：
  - 消息铃铛（带小红点数字徽标，实时显示未读私信及系统通知）。
  - 用户头像 + 昵称（悬停下拉菜单：个人主页、设置、退出登录）。
  - 暗色主题切换开关（月牙/太阳图标，带平滑旋转过渡）。

### 2. 竖向侧边栏（左侧固定）
- **顶部**：放置应用 Logo（点击返回主页，与顶部呼应）。
- **中部（纵向排列）**：
  1. **主页**（房子图标）— 默认选中。
  2. **发布按钮**（+ 图标，置于主页下方，视觉上略突出）— 点击弹出快捷菜单：【发图文博客】/【发视频】/【创建新社区】。
  3. **频道**（旗帜图标）— 我的社区聚合。
  4. **会话**（聊天气泡图标）— 好友与群聊。
  5. **探索/动态**（指南针/火花图标）— 发现全网热门或关注者的实时动态。
- **底部**：**侧边栏收缩/展开控制按钮**（双箭头图标），置于底部居中。收缩时仅显示图标，悬停弹出文字提示；且"发布"按钮收缩后变为彩色圆形浮动按钮（FAB），常驻于收缩栏中部。

## 三、 各核心功能模块详细设计

### 1. 主页（首页信息流）
- **布局**：主内容区采用 3列等宽网格，间距 20px，滚动到底部自动加载更多（骨架屏占位）。
- **卡片类型与比例**：
  - 图文博客 → 竖长方形（9:16），封面图置于顶部。
  - 视频内容 → 正方形（1:1），封面图带播放按钮悬浮层（悬停时放大）。
- **卡片结构（自上而下）**：
  1. **封面区**：圆角图片，加载失败显示柔和占位色。
  2. **用户信息栏**：左侧小尺寸圆形头像 + 右侧昵称（超长省略），右上角显示发布时间（如"3分钟前"）。
  3. **标题/简述**：最多显示 2 行，超出省略。
  4. **底部互动栏**：左侧：喜欢（❤️ + 数量，点击爱心填充动画并 +1）。右侧：收藏（⭐️ + 数量，点击星标变色）。
  5. **补充**：卡片右上角悬浮"更多"操作按钮（举报/屏蔽该内容）。
- **卡片点击行为**：点击卡片任意区域（除互动按钮外）→ 进入内容详情页。

### 2. 频道模块（社区聚合）
- **交互逻辑**：点击侧边栏"频道"，主内容区切换为左右分栏（1:2 比例）。
- **左侧列表**：展示"我加入的频道"，列表项含频道头像、名称及未读消息小红点。底部固定入口："发现新频道"（点击跳转频道推荐广场）。
- **右侧主视窗**：顶部：选中频道的 Banner 头图 + 简介，右上角显示"退出频道"按钮（二次确认）。下方：该频道内的动态流（沿用主页 3列卡片网格）。
- **空状态**：插画风格空状态图 + 引导文案"快来发布第一条动态吧"。
- **交互细节**：点击左侧不同频道，右侧内容无缝刷新，顶部显示"当前所在频道"标签。点击任意卡片 → 跳转至内容详情页。

### 3. 会话模块（实时通讯）
- **交互逻辑**：点击侧边栏"会话"，主内容区切换为左右分栏（1:2 比例）。
- **左侧列表**：顶部 Tab 切换：【好友列表】 | 【群聊列表】。好友列表项显示：头像、昵称、实时在线状态（绿点/灰点）、最近一条消息预览（含时间戳）。列表按最近活跃时间排序，置顶未读会话。
- **右侧聊天窗**：顶部：对方/群组名称 + 在线状态（群组显示成员数）。中部：消息气泡流（对方靠左灰底、自己靠右品牌色）。底部：固定输入框（文字、Emoji、图片/视频文件上传，Enter 快速发送）。
- **实时感增强**：模拟显示"对方正在输入..."状态提示；新消息到达时聊天窗自动滚动至底部并伴有轻微闪烁提示。

### 4. 用户个人页面（个人空间）
- **触发方式**：点击顶部导航栏头像 或 侧边栏底部"我的"入口。
- **布局**：左右分栏，左侧为竖排功能工具栏（固定宽度 220px）。
- **左侧工具栏**：**作品**（默认选中）/ **收藏** / **文件**（多媒体素材库，按类型分类，支持预览和下载）/ **账号与安全**（账号绑定、密码修改、登录设备管理）。
- **右侧内容区**：头部信息（背景图、居中大号圆形头像、昵称、个性签名、关注/粉丝/获赞数统计卡片）+ 内容主体（默认"作品"Tab，3列网格展示所有图文/视频卡片）。
- **联动逻辑**：点击"收藏"Tab → 切换显示收藏内容；点击"安全"Tab → 切换为账号安全设置表单。

### 5. 内容详情页（卡片查看页面）
**触发方式**：点击主页、频道、个人页面中的任意卡片，主内容区平滑右滑切入详情视图。
**返回逻辑**：详情页左上角固定显示"← 返回"按钮（返回上一级信息流，保留浏览位置）；支持键盘 ESC 键关闭详情页。
**整体布局**：左右分栏结构（6 : 4 比例），顶部导航栏和左侧边栏置灰/模糊化，但保持可见。

#### 左侧主视窗（内容展示区，占比 60%）
- **顶部导航条（详情页专用）**：左侧返回按钮；右侧内容类型标签（如"# 图文博客" 或 "# 视频"）+ 更多操作按钮（··· 举报/屏蔽）。
- **内容主体**：
  - **图文博客模式**：封面大图/轮播图（多图左右滑动，底部缩略图指示点）；正文标题（大号加粗）；富文本正文（段落间距、引用块、@提及，行高 1.8 倍）。
  - **视频模式（含弹幕系统）**：
    - 视频播放器（16:9，自适应宽度）：自定义播放控件（播放/暂停、可拖拽进度条、音量、全屏）。右下角弹幕开关按钮（💬），默认为开启状态，关闭后隐藏弹幕并暂停渲染。
    - 弹幕显示区（覆盖于视频画面，透明度可调）：
      - 从右向左匀速滚动，轨迹随机分布在画面上中下区域；同时最多 15~20 条，超出排队。
      - 字体统一 16px，颜色支持自定义（预设 8 种热门色 + 随机色），默认白色带半透明描边；透明度默认 70%（设置可调 50%~100%）。
      - 敏感词命中自动拦截并提示"内容包含违规词汇，请修改"；长按/右键弹幕弹出菜单：【屏蔽该用户弹幕】、【举报】。
    - 弹幕发送区（播放器下方评论输入框左侧新增"发弹幕"按钮 ✉️）：
      - 点击后占位符切换为"发一条有趣的弹幕吧..."，Enter/发送后弹幕立即出现在视频画面（实时推送）。
      - 限制：每条 ≤30 字符，发送间隔 ≥3 秒（防刷屏）。
      - 反馈：自己发送的弹幕以品牌色高亮标记 2 秒；点击弹幕可点赞（👍），点赞 >10 升级为"热门弹幕"（星标特效、18px、停留时间延长 1 秒）。
    - 弹幕与评论区关系：弹幕即时轻量不存入评论列表；评论区深度讨论。元数据增加"弹幕数"（如"💬 1,283条弹幕"），点击查看热门弹幕排行榜。
    - 视觉适配：圆体/柔和字体（非衬线）；无气泡底框仅靠描边；暗色模式下默认浅灰色（#E0E0E0）。
- **内容元数据**：发布时间、所属频道（可点击跳转）、浏览数。

#### 右侧边栏（互动与社交区，占比 40%，固定不滚动）
- **顶部：发布者信息卡片**：大号圆形头像（点击跳转个人主页）+ 昵称/签名 + **"关注"按钮**（未关注主色填充；已关注灰色描边，悬停变"取关"红色提示）。
- **中部：核心互动栏**：❤️ 喜欢（填充动画 +1）、⭐️ 收藏（星标变色）、💬 评论数（锚点滚动至评论区）、🔗 分享链接（复制链接 + "已复制"轻提示）。
- **底部：评论区（独立滚动）**：顶部提示"全部评论 (XX条)"；评论列表（时间倒序/热门排序切换）；每条含头像/昵称/内容/时间/回复按钮；嵌套回复（二级，缩进，最多显示 3 条，超出折叠"查看更多回复"）；底部固定输入框（占位符"说点什么... (支持 Enter 发送)"、Emoji 面板、发送后乐观更新 + 上滑动画）。
- **视频内容的特殊处理**：右侧"关注"按钮下方增加"相关推荐"区域（同一频道其他热门视频卡片，横向滑动，点击无缝切换详情）。
- **交互反馈**：骨架屏 + 淡入；评论为空显示插画 + "还没有评论，快来抢沙发吧～"；作者本人视角："关注"按钮替换为"编辑内容"按钮，互动栏下方显示内容数据统计。
- **页面切换衔接**：详情页内 @提及/头像跳转他人主页时覆盖替换（保留返回堆栈），逐级回退。

## 四、 全局补充规范

| 项目 | 说明 |
|------|------|
| 加载状态 | 滚动到底部触发"加载更多"，显示骨架屏（Skeleton Screen）占位，避免全屏加载转圈。 |
| 空状态 | 所有列表（频道、收藏、文件、会话）无数据时，统一使用插画 + 引导文案，不展示空白占位。 |
| 消息红点 | 仅当存在未读消息时显示，点击进入对应模块后自动清除该模块红点。 |
| Toast 提示 | 操作成功/失败时，从顶部导航栏下方滑出轻提示（3秒自动消失），不阻塞用户操作。 |
| 响应式适配 | PC/Web 为主，侧边栏收缩后，主内容区三列网格自适应为两列（窗口宽度 < 1200px 时）。 |
| 弹幕开关记忆 | 用户在每个视频上的弹幕开关状态，随账号保存，下次观看恢复上次偏好。 |
| 弹幕速率控制 | 播放器设置中可调节弹幕滚动速度（慢/中/快三档），默认"中"。 |
| 弹幕防遮挡 | 视频进度条和控制栏浮现时，弹幕自动上移或透明度提高，避免遮挡操作按钮。 |
