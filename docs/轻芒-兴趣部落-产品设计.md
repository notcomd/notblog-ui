# 轻芒 · 兴趣部落 —— 产品设计文档（完整版）

**项目名称**：轻芒 · 兴趣部落（暂代）  
**项目定位**：一个氛围轻松、低压迫感、实时在线的兴趣博客社区。面向普通用户，强调"沉浸式浏览"与"即时互动"。

---

## 一、 整体风格与设计基调

- **视觉风格**：采用**毛玻璃质感**与**大圆角**结合，背景使用柔和的渐变色或微动效模糊背景，营造呼吸感。
- **色彩体系**：主色调为低饱和度的中性色（奶白、浅灰）搭配品牌点缀色（暖橘或薄荷绿）。文字层级清晰，减少视觉噪音。
- **暗色模式**：全局支持一键切换深色/浅色主题，切换动画需流畅自然（颜色渐变过渡）。
- **交互反馈**：所有可点击元素需包含 `Hover` 悬浮微动效（上浮、阴影变化）和 `Click` 触感反馈（水波纹或轻触缩放）。

---

## 二、 全局布局与框架

采用经典的 **"左导航 + 右内容"** 双栏结构：

### 1. 顶部导航栏（全局固定）
- **左侧**：展示应用 Logo 与名称（点击返回主页）。
- **中部**：全局搜索框（占位符："搜兴趣、找好友、看热门..."），支持 `Enter` 触发全站模糊搜索。
- **右侧（从左至右）**：
  - 消息铃铛（带小红点数字徽标，实时显示未读私信及系统通知）。
  - 用户头像 + 昵称（悬停下拉菜单：个人主页、设置、退出登录）。
  - 暗色主题切换开关（月牙/太阳图标，带平滑旋转过渡）。

### 2. 竖向侧边栏（左侧固定）
- **顶部**：放置应用 Logo（点击返回主页，与顶部呼应）。
- **中部（纵向排列）**：
  1. **主页**（房子图标）— 默认选中。
  2. **发布按钮**（`+` 图标，置于主页下方，视觉上略突出）— 点击弹出快捷菜单：【发图文博客】/【发视频】/【创建新社区】。
  3. **频道**（旗帜图标）— 我的社区聚合。
  4. **会话**（聊天气泡图标）— 好友与群聊。
  5. **探索/动态**（指南针/火花图标）— 发现全网热门或关注者的实时动态。
- **底部**：**侧边栏收缩/展开控制按钮**（双箭头图标），置于底部居中。收缩时仅显示图标，悬停弹出文字提示；且"发布"按钮收缩后变为彩色圆形浮动按钮（FAB），常驻于收缩栏中部。

## 三、 各核心功能模块详细设计

### 1. 主页（首页信息流）
- **布局**：主内容区采用 **3列等宽网格**，间距 20px，滚动到底部自动加载更多（骨架屏占位）。
- **卡片类型与比例**：
  - **图文博客** → 竖长方形（9:16），封面图置于顶部。
  - **视频内容** → 正方形（1:1），封面图带播放按钮悬浮层（悬停时放大）。
- **卡片结构（自上而下）**：
  1. **封面区**：圆角图片，加载失败显示柔和占位色。
  2. **用户信息栏**：左侧小尺寸圆形头像 + 右侧昵称（超长省略），右上角显示发布时间（如"3分钟前"）。
  3. **标题/简述**：最多显示 2 行，超出省略。
  4. **底部互动栏**：
     - 左侧：**喜欢**（❤️ + 数量，点击爱心填充动画并 +1）。
     - 右侧：**收藏**（⭐️ + 数量，点击星标变色）。
  5. **补充**：卡片右上角悬浮"更多"操作按钮（举报/屏蔽该内容）。
- **卡片点击行为**：点击卡片任意区域（除互动按钮外）→ 进入 **第 5 节·内容详情页**。

---

### 2. 频道模块（社区聚合）
- **交互逻辑**：点击侧边栏"频道"，主内容区切换为 **左右分栏（1:2 比例）**。
- **左侧列表**：
  - 展示"我加入的频道"，列表项含频道头像、名称及**未读消息小红点**。
  - 底部固定入口："发现新频道"（点击跳转频道推荐广场）。
- **右侧主视窗**：
  - 顶部：选中频道的 **Banner 头图 + 简介**，右上角显示"退出频道"按钮（二次确认）。
  - 下方：该频道内的动态流（沿用主页 3列卡片网格，展示成员发布的图文/音视频）。
- **空状态**：若频道内暂无内容，展示插画风格空状态图 + 引导文案"快来发布第一条动态吧"。
- **交互细节**：点击左侧不同频道，右侧内容无缝刷新，顶部显示"当前所在频道"标签。点击任意卡片 → 跳转至 **第 5 节·内容详情页**。

---

### 3. 会话模块（实时通讯）
- **交互逻辑**：点击侧边栏"会话"，主内容区切换为 **左右分栏（1:2 比例）**。
- **左侧列表**：
  - 顶部 Tab 切换：【好友列表】 | 【群聊列表】。
  - 好友列表项显示：头像、昵称、**实时在线状态（绿点/灰点）**、最近一条消息预览（含时间戳）。
  - 列表支持按最近活跃时间排序，置顶未读会话。
- **右侧聊天窗**：
  - **顶部**：对方/群组名称 + 在线状态（群组显示成员数）。
  - **中部**：消息气泡流（对方气泡靠左、灰色背景；自己气泡靠右、品牌色背景）。
  - **底部**：固定输入框（支持文字、Emoji、图片/视频文件上传，支持 `Enter` 快速发送）。
- **实时感增强**：模拟显示"对方正在输入..."状态提示；新消息到达时，聊天窗自动滚动至底部并伴有轻微闪烁提示。

---

### 4. 用户个人页面（个人空间）
- **触发方式**：点击顶部导航栏头像 或 侧边栏底部"我的"入口。
- **布局**：同样采用 **左右分栏**，左侧为竖排功能工具栏。
- **左侧工具栏**（固定宽度 220px）：
  - **作品**（默认选中）— 展示用户发布的内容。
  - **收藏** — 展示用户收藏的内容。
  - **文件** — 展示用户上传的图片/视频/文档等多媒体素材库（按类型分类，支持预览和下载）。
  - **账号与安全** — 账号绑定、密码修改、登录设备管理。
- **右侧内容区**：
  - **头部信息**：背景图（可自定义）、居中大号圆形头像、用户昵称、个性签名、关注/粉丝/获赞数统计卡片。
  - **内容主体**：默认展示"作品"Tab，以 3列网格展示所有图文/视频卡片（点击卡片 → 跳转至 **第 5 节·内容详情页**）。
- **联动逻辑**：点击"收藏"Tab → 切换显示收藏内容；点击"安全"Tab → 切换为账号安全设置表单。

---

### 5. 内容详情页（卡片查看页面）
**触发方式**：点击主页、频道、个人页面中的任意卡片（图文或视频），主内容区平滑右滑切入详情视图。  
**返回逻辑**：详情页左上角固定显示"← 返回"按钮（点击返回上一级信息流，保留浏览位置）；同时支持键盘 `ESC` 键关闭详情页。  
**整体布局**：采用 **左右分栏结构（6 : 4 比例）**，顶部导航栏和左侧边栏置灰/模糊化，但保持可见（不干扰操作）。

#### 左侧主视窗（内容展示区，占比 60%）
- **顶部导航条（详情页专用）**：
  - 左侧：返回按钮（← 返回）。
  - 右侧：内容类型标签（如"# 图文博客" 或 "# 视频"）+ 更多操作按钮（··· 举报/屏蔽）。
- **内容主体（垂直居中或滚动浏览）**：

  **图文博客模式**：
  - 封面大图/轮播图（若多图，支持左右滑动切换，底部带缩略图指示点）。
  - 正文标题（大号、加粗）。
  - 富文本正文（支持段落间距、引用块、@提及，字体大小适中，行高 1.8 倍）。

  **视频模式（含弹幕系统）**：
  - **视频播放器**（16:9 宽屏，自适应宽度）：
    - 自定义播放控件：播放/暂停、进度条（可拖拽）、音量控制、全屏模式。
    - **弹幕开关**：播放器右下角新增弹幕开关按钮（`💬` 图标），默认为开启状态。关闭后隐藏所有弹幕，同时暂停弹幕渲染以节省性能。
  - **弹幕显示区**（覆盖于视频画面上方，透明度可调）：
    - **显示规则**：
      - 弹幕从画面右侧向左匀速滚动，每条弹幕轨迹随机分布在画面上、中、下区域（避免集中在同一水平线）。
      - 同一时刻画面内最多同时显示 **15～20 条** 弹幕，超出部分排队等候，待有空间后依次进入。
      - 弹幕字体大小统一（16px），颜色支持用户自定义（预设 8 种热门色 + 随机色），但默认以 **白色带半透明描边** 显示，确保在任何画面背景下均可清晰阅读。
      - 弹幕透明度默认为 70%，用户可在设置中调整透明度（50%～100%）。
    - **弹幕过滤与防护**：
      - 系统内置敏感词库，发送的弹幕命中敏感词后自动拦截并提示"内容包含违规词汇，请修改"。
      - 用户可**长按/右键点击**任意弹幕，弹出菜单：【屏蔽该用户弹幕】、【举报】。屏蔽后该用户的全部弹幕在当前视频内不再显示。
  - **弹幕发送区**（位于视频播放器下方，输入框旁新增发送入口）：
    - **快捷发送入口**：视频下方的评论输入框左侧增加一个 **"发弹幕"按钮**（`✉️` 图标），点击后输入框占位符切换为"发一条有趣的弹幕吧..."，输入内容后按 `Enter` 或点击发送按钮，弹幕立即出现在视频画面上（实时推送，无需刷新）。
    - **弹幕发送限制**：每条弹幕长度不超过 **30 个字符**，发送间隔不低于 **3 秒**（防刷屏）。
    - **弹幕互动反馈**：用户发送弹幕后，该条弹幕会以**高亮颜色（品牌色）** 短暂标记（持续 2 秒），让发送者能快速识别自己的弹幕。
    - **弹幕点赞**：用户可点击任意弹幕为其"点赞"（👍），点赞数超过 **10 次** 的弹幕将升级为 **"热门弹幕"**，显示时带有星标特效，并略微放大字号（18px），停留时间延长 1 秒。
  - **弹幕与评论区的关系**：
    - 弹幕是即时、轻量的情感表达，不存入评论列表；评论区用于深度讨论。两者互不干扰，形成"上层热闹（弹幕）+ 下层深度（评论）"的双层互动结构。
    - 视频详情页的元数据中增加 **"弹幕数"** 展示（如"💬 1,283条弹幕"），点击可查看热门弹幕排行榜（按点赞数排序）。
  - **弹幕视觉风格适配**：
    - 弹幕文字采用**圆体或柔和字体**（非衬线），与整体"轻松、毛玻璃"风格一致。
    - 弹幕背景不添加任何气泡或底框，保持轻盈感，仅依赖文字本身的描边实现可读性。
    - 暗色模式下，弹幕默认颜色调整为**浅灰色**（#E0E0E0），避免高亮白色在暗色背景下过于刺眼。

- **内容元数据**：在正文下方显示发布时间、所属频道（点击可跳转至该频道）、浏览数。

#### 右侧边栏（互动与社交区，占比 40%，固定不滚动）
- **顶部：发布者信息卡片**（固定）：
  - 左侧：大号圆形头像（点击跳转至该用户个人主页）。
  - 中部：用户昵称 + 个性签名（超长省略）。
  - 右侧：**"关注"按钮**（未关注时显示为主色填充按钮，已关注显示为"已关注"灰色描边按钮，悬停变为"取关"红色提示）。
- **中部：核心互动栏（横向分布，图标+数字）**：
  - ❤️ 喜欢（点击爱心填充动画并 +1，数字实时更新）。
  - ⭐️ 收藏（点击星标变色，数字实时更新）。
  - 💬 评论数（点击可自动锚点滚动至评论区）。
  - 🔗 分享链接（点击复制当前内容链接至剪贴板，弹出"已复制"轻提示）。
- **底部：评论区（占据右侧边栏主要高度，独立滚动）**：
  - **顶部提示**：显示"全部评论 (XX条)"。
  - **评论列表**（按时间倒序 / 热门排序切换）：
    - 每条评论项包含：评论者小头像、昵称、评论内容、发布时间、回复按钮。
    - 支持嵌套回复（二级评论，缩进展示，最多显示 3 条，超出折叠显示"查看更多回复"）。
  - **底部固定输入框**：
    - 占位符："说点什么... (支持 Enter 发送)"。
    - 右侧附带 Emoji 表情选择按钮（点击弹出表情面板）。
    - 发送后评论立即出现在列表顶部（乐观更新），并伴有轻微上滑动画。

#### 视频内容的特殊处理
当详情页左侧为视频内容时，评论区与互动栏保持不变，但右侧顶部的"关注"按钮下方会额外增加一条 **"相关推荐"** 区域（展示同一频道下的其他热门视频卡片，横向滑动，点击无缝切换详情，无需返回）。

#### 交互反馈与状态
- **加载状态**：详情页打开时，封面/视频区域展示柔和占位色 + 呼吸动画骨架屏，内容加载完成后淡入显示。
- **评论为空时**：评论区中央展示插画 + 文案"还没有评论，快来抢沙发吧～"。
- **作者本人视角**：如果当前登录用户是该内容的作者，右侧边栏的"关注"按钮替换为 **"编辑内容"** 按钮（点击进入编辑模式），且互动栏下方显示"内容数据统计"（阅读量、点赞来源等）。

#### 页面切换衔接
在详情页内，如果用户点击评论中的 @提及 或发布者头像跳转至他人个人主页，详情页将被覆盖替换（保留返回堆栈），点击新页面的返回按钮可逐级回退，确保浏览路径不丢失。

## 四、 全局补充规范

| 项目 | 说明 |
|------|------|
| **加载状态** | 滚动到底部触发"加载更多"，显示骨架屏（Skeleton Screen）占位，避免全屏加载转圈。 |
| **空状态** | 所有列表（频道、收藏、文件、会话）无数据时，统一使用插画 + 引导文案，不展示空白占位。 |
| **消息红点** | 仅当存在未读消息时显示，点击进入对应模块后自动清除该模块红点。 |
| **Toast 提示** | 操作成功/失败时，从顶部导航栏下方滑出轻提示（3秒自动消失），不阻塞用户操作。 |
| **响应式适配** | PC/Web 为主，侧边栏收缩后，主内容区三列网格自适应为两列（窗口宽度 < 1200px 时）。 |
| **弹幕开关记忆** | 用户在每个视频上的弹幕开关状态，随账号保存。下次观看该视频时恢复上次偏好。 |
| **弹幕速率控制** | 用户可在播放器设置中调节弹幕滚动速度（慢/中/快三档），默认"中"。 |
| **弹幕防遮挡** | 视频进度条和控制栏浮现时，弹幕自动上移或透明度提高，避免遮挡操作按钮。 |
| **背景图与深/浅模式联动** | 切换深/浅模式时，背景图的遮罩参数自动适配（浅色模式降低压暗强度，深色模式增加压暗强度），确保始终可读。 |
| **背景图加载失败处理** | 若背景图 404 或加载超时（3 秒），自动回退至当前皮肤的基础纯色，并显示轻提示"背景图加载失败，已切换纯色模式"。 |
| **默认背景图策略** | 新用户首次登录时不加载背景图，仅使用"轻芒白"纯色，引导用户自主选择是否开启背景图（避免初次加载过重）。 |
| **帧率优化** | 背景图使用 `will-change: transform` 与 `translateZ(0)` 启动 GPU 加速，防止滚动时掉帧。 |

## 五、 前端皮肤系统与背景图系统（皮肤系统增强版）

**皮肤系统 = 颜色皮肤（浅/深模式，品牌色可扩展）+ 背景图系统（平行扩展层）**。背景图独立于品牌色与深/浅模式，用户可自由组合「颜色皮肤 + 背景图片」，让每个兴趣部落拥有独一无二的视觉情绪。

### 1. 核心理念与图层架构

背景图片是一层独立的"氛围底衬"，不干扰品牌色、不破坏毛玻璃质感，实现 **"前景清晰（内容/卡片）"** 与 **"后景灵动（背景图）"** 的完美分层。

Z-index 图层堆叠顺序（由底至上）：

1. **基底图层**：纯色背景（由当前皮肤的基础色决定，作为背景图缺失/加载失败时的回退）。
2. **背景图片层**：用户选择或上传的图片（`background-image`），裁剪覆盖全屏。
3. **氛围遮罩层**：半透明渐变/纯色蒙层（**关键设计**），压暗并柔和背景图，保证前景文字与卡片符合 WCAG 可读性标准；另叠加**四周向中心的渐变压暗**，确保白色文字在任何背景下清晰。
4. **毛玻璃元素层**：导航栏、卡片、侧边栏等（`backdrop-filter: blur()`），透过它们能隐约看到背景图，营造通透感。

### 2. 背景图来源与获取方式

皮肤面板「背景设置」Tab 提供三种图片来源：

| 来源类型 | 说明 | 适用场景 |
|----------|------|----------|
| **官方预设壁纸** | 内置 12 张精选壁纸（抽象渐变为主），按风格分类（清新/深邃/暖阳/极简）。 | 一键换肤，质量可控，加载迅速（一期为本地 SVG 生成，离线可用；二期可替换 WebP 真图）。 |
| **自定义上传** | 用户上传本地图片（JPG/PNG/WebP），上传前自动压缩。 | 个性化程度最高（**已实现（2026-08 二期）**：Canvas 压缩 ≤1920px/质量 0.8、WebP 转码、5MB 配额、上传新图覆盖旧图、后端不可用时本地 dataURI 兜底仅本机可见）。 |
| **纯色/渐变（默认）** | 关闭背景图，仅显示当前皮肤定义的纯色或柔和渐变背景。 | 极简阅读体验或省流模式。 |

### 3. 背景图的交互与控制（用户端）

**入口**：顶部「调色板」图标 → 皮肤面板 → 【颜色皮肤】与【背景设置】两个并列 Tab。

【背景设置】Tab 内容：

- **顶部预览窗**：小型毛玻璃卡片预览区，实时展示当前背景图 + 遮罩效果，所见即所得。
- **中部选择区**：按分类横向滚动的官方壁纸缩略图（圆角矩形，选中高亮边框）。
- **底部操作栏**：上传自定义图片（二期开放）、移除背景图（恢复纯色/渐变默认）、遮罩控制滑块。

**遮罩与可读性保护（关键设计，自动叠加不可关闭）**：

- 渐变压暗层：从四周向中心渐变的半透明黑色（约 `rgba(0,0,0,0.2)` → `rgba(0,0,0,0.6)`）。
- 毛玻璃基底适配：浅色皮肤遮罩偏向柔光（`rgba(255,255,255,0.1)` + 黑色微压）；深色皮肤遮罩偏向深色吸光。
- 用户滑块：
  - **背景虚化/模糊度**：`blur` 0~12px，默认 4px。模糊越高背景越柔和、文字越清晰。
  - **蒙层深浅**：遮罩透明度 20%~80%，默认 40%。调高让背景图几乎隐去、专注内容；调低背景更突出。
- **自动安全阈值**：蒙层滑块最小值强制 ≥20%，防止调至 0% 导致界面不可读。

### 4. 管理端的背景图策略

- **默认强制**：管理后台默认使用"暮色深蓝"纯色背景，**不加载任何背景图**，保持专注高效（前端实现：管理端布局不挂载背景图层）。
- **管理员可选**（二期）：允许超级管理员在个人设置中开启背景图（仅对自己生效），且仅限官方预设壁纸（禁止自定义上传，防止敏感图片泄露）。

### 5. 背景图管理（管理端「文件管理」模块，二期进行中）

- 「文件管理」新增分类筛选【用户壁纸】。
- 用户上传的自定义背景图默认"仅自己可见"，后台记录；运营人员发现违规内容可【删除图片】并【封禁用户】；删除后该用户端背景图自动回退为默认纯色。

### 6. 性能优化与开发规范

| 优化点 | 实施方案 |
|--------|----------|
| **图片压缩** | 上传时前端 Canvas 压缩（最大宽度 1920px、质量 0.8），减少存储与带宽消耗。 |
| **懒加载** | 背景图使用 `background-image` + JS 预加载（`Image()` 对象），加载失败或 3 秒超时自动回退纯色。 |
| **缓存策略** | 背景图选择存 `localStorage`（`qingmang_skin`）；一期内置壁纸为 data-URI 零网络请求。 |
| **WebP 优先** | 官方预设壁纸提供 WebP 并回退 JPG；用户上传转码 WebP（二期）。 |
| **存储限制** | 每个用户背景图配额 5MB，仅保存最新一张，上传新图自动覆盖旧图。 |

### 7. 皮肤与背景的组合逻辑（用户可见规则）

| 组合场景 | 显示效果 |
|----------|----------|
| 浅色皮肤 + 无背景图 | 皮肤定义的奶白渐变背景。 |
| 浅色皮肤 + 背景图 | 背景图作为底层（浅色遮罩偏柔光），毛玻璃卡片浮于上方，透过模糊可见背景。 |
| 深色皮肤 + 无背景图 | 皮肤定义的深灰/藏青纯色背景。 |
| 深色皮肤 + 背景图 | 背景图被深色遮罩强力压暗，毛玻璃卡片呈"深色半透明"质感。 |
| 切换颜色皮肤（不变背景图） | 背景图保持不变，品牌色与基础文字颜色随皮肤变化。 |
