# 轻芒 · 兴趣部落 —— 管理端产品设计文档

**项目名称**：轻芒 · 兴趣部落（管理后台）
**项目定位**：为社区运营人员提供高效、清晰、可视化的管理工具，实现对用户、内容、社区及系统消息的全面管控。延续用户端"轻松、低压迫感"的视觉基因，但适度增加**数据可视性与操作效率**，打造"张弛有度"的后台体验。

---

## 一、 整体风格与设计基调

- **视觉风格**：延续用户端的**毛玻璃质感**与**大圆角**，但背景采用更沉稳的**深色渐变或磨砂深灰**（暗色模式为默认），营造专注、专业的管理氛围。
- **色彩体系**：主色调为**深蓝/藏青**（稳重、可信）搭配**暖橘/翠绿**作为功能点缀色（如审核通过、在线状态）。数据看板区域使用**柔和渐变色卡片**区分不同模块。
- **暗色模式**：管理端默认采用**深色主题**（符合后台工具场景），同时提供浅色模式选项，切换动画顺滑。
- **交互反馈**：所有操作按钮（审核、封禁、删除等）需包含明确的 `Hover` 和 `Click` 反馈，**危险操作（如删除、封禁）** 必须触发**二次确认弹窗**，防止误触。

---

## 二、 全局布局与框架

采用 **"顶栏 + 左栏 + 主内容"** 三明治结构，与用户端保持一致的布局基因：

### 1. 顶部导航栏（全局固定）
- **左侧**：展示应用 Logo 与名称（点击返回管理端主页），右侧标注 **"管理后台 · 运营版"** 小字。
- **中部**：全局搜索框（占位符："搜索用户ID、内容标题、社区名称..."），支持 `Enter` 触发全站管理检索。
- **右侧（从左至右）**：
  - **系统通知铃铛**（带小红点，展示系统告警、审核堆积等运营提醒）。
  - **管理员头像 + 昵称**（悬停下拉菜单：个人中心、操作日志、退出登录）。
  - **暗色/浅色主题切换开关**（月牙/太阳图标）。

### 2. 竖向侧边栏（左侧固定，功能导航总控）
- **顶部**：放置应用 Logo（点击返回管理端主页）。
- **中部（纵向排列，导航图标+文字）**，顺序按管理优先级排列：
  1. **工作台/总览**（仪表盘图标）— 默认选中，展示全站数据汇总。
  2. **用户管理**（👤 用户图标）— 用户列表与管控。
  3. **内容管理**（📄 文档图标）— 图文/视频/博客审核。
  4. **举报管理**（🚩 旗帜图标）— 处理用户举报。
  5. **社区管理**（🏠 社区图标）— 社区与会话管控。
  6. **文件管理**（📁 文件夹图标）— 用户上传文件管理。
  7. **公报**（📢 喇叭图标，视觉高亮）— 系统消息发送（全体/个体/社区）。
- **底部**：**侧边栏收缩/展开控制按钮**（双箭头图标），收缩时仅显示图标，悬停弹出文字提示。

---

## 三、 各核心功能模块详细设计

### 1. 工作台/总览（管理端主页）
**布局**：主内容区采用 **4列等宽网格**（间距 20px），顶部为全局数据卡片，下方为动态列表。

- **顶部统计卡片（4张并列）**：
  1. **总注册用户**（👥）+ 较昨日增长百分比（绿色上涨/红色下降）。
  2. **当前在线人数**（🟢 绿点动画）+ 实时刷新（WebSocket 推送）。
  3. **待审核内容数**（⏳ 黄色警示）+ 点击跳转至内容管理。
  4. **未处理举报数**（🚩 红色警示）+ 点击跳转至举报管理。
- **中部：快捷操作区**：
  - 【发布系统公告】按钮（跳转至公报模块）。
  - 【导出运营日报】按钮（生成 CSV/PDF 报表）。
- **底部：最近动态列表**（按时间倒序）：
  - 显示最近的用户注册、内容发布、举报提交、审核操作等日志，每条日志带时间戳和操作类型标签。

---

### 2. 用户管理
**交互逻辑**：点击侧边栏"用户管理"，主内容区展示 **用户列表（表格视图）**。

- **顶部操作栏**：
  - 左侧：【添加用户】按钮（弹出表单：用户名、邮箱、初始密码、角色分配）。
  - 右侧：搜索框（按用户名/ID/邮箱检索）+ 状态筛选下拉（全部 / 正常 / 已封禁）。
- **用户列表（表格列）**：
  1. 用户 ID（系统唯一标识）。
  2. 头像 + 昵称。
  3. 注册时间。
  4. 最后在线时间（显示"X分钟前"或"离线"）。
  5. 状态（✅ 正常 / ⛔ 已封禁 / 🟢 在线中）。
  6. 操作栏（每行右侧）：
     - 【查看】— 弹出用户信息详情窗（含发布记录、封禁历史）。
     - 【封禁】— 弹出二次确认框，填写封禁原因和时长（永久/7天/30天）。
     - 【删除】— 弹出二次确认框，确认后彻底删除该用户所有数据（含内容、评论、文件）。
- **批量操作**：列表顶部支持勾选框，可批量【封禁】或【删除】所选用户。
- **在线人数查看**：顶部统计卡片"当前在线人数"点击后弹出**在线用户实时列表**（WebSocket 推送，展示在线用户 ID + 昵称 + 当前所在页面）。

---

### 3. 内容管理
**交互逻辑**：点击侧边栏"内容管理"，主内容区切换为 **Tab 切换视图**：【图文】| 【视频】| 【博客】。

- **顶部筛选栏**：
  - 状态筛选下拉：全部 / 待审核 / 已通过 / 已驳回。
  - 时间排序：最新发布 / 最多举报。
  - 搜索框：按内容标题/作者昵称检索。
- **内容列表（卡片/表格混合视图）**：
  - 每条内容展示：封面缩略图 + 标题 + 作者昵称 + 发布时间 + 当前状态标签（待审核/已通过/已驳回）。
  - **操作栏**：
    - 【审核】— 弹出审核弹窗，显示完整内容预览（图文正文 / 视频播放），下方提供【通过】/ 【驳回】按钮。驳回时需填写驳回理由（选填），理由将反馈给发布者。
    - 【屏蔽】— 直接隐藏该内容（不删除，但全站不可见），需填写屏蔽原因。
    - 【删除】— 二次确认后永久删除。
- **审核队列优先级**：待审核内容按**举报次数 > 发布时间**排序，高举报内容置顶显示红色警示边框。

---

### 4. 举报管理
**交互逻辑**：点击侧边栏"举报管理"，主内容区展示 **举报工单列表**。

- **顶部统计**：显示"待处理 X 条 / 已处理 X 条"。
- **举报列表（表格视图）**：
  1. 举报编号。
  2. 举报目标（内容标题/用户昵称，点击可跳转预览）。
  3. 举报类型（色情 / 暴力 / 政治 / 广告 / 其他）。
  4. 举报人（匿名显示为"匿名用户"）。
  5. 提交时间。
  6. 状态（待处理 / 已处理）。
  7. 操作栏：
     - 【查看详情】— 弹出侧滑面板，展示被举报内容/用户的完整信息、举报人留言、历史举报记录。
     - 【标记处理】— 选择处理结果：**驳回举报**（内容正常）/ **删除内容** / **封禁用户**，并填写处理备注。
- **批量处理**：支持多选举报工单，一键【全部标记为已处理】。

---

### 5. 社区管理
**交互逻辑**：点击侧边栏"社区管理"，主内容区切换为 **左右分栏（1:2 比例）**，与用户端频道模块一致。

- **左侧列表**：展示全平台所有**社区列表**，包含社区头像、名称、成员数、创建时间。顶部搜索框支持按名称检索。
- **右侧详情区**（点击左侧社区后显示）：
  - **社区概览**：Banner 头图 + 社区名称 + 简介 + 创建者 + 成员数/帖子数统计。
  - **操作按钮**（位于概览下方）：
    - 【封禁社区】— 弹出二次确认框，封禁后社区全站不可见，所有成员收到系统通知。
    - 【解散社区】— 弹出二次确认框，彻底删除社区及所有内容（不可恢复）。
    - 【转让社区】— 弹出表单，搜索并选择新创建者（仅限现有成员）。
  - **下方 Tab 切换**：【成员列表】| 【会话列表】。
    - **成员列表**：展示所有成员头像、昵称、加入时间、角色（创建者/管理员/普通成员），支持【移除成员】操作。
    - **会话列表**：展示该社区下的所有群聊会话，支持【解散会话】操作。

---

### 6. 文件管理
**交互逻辑**：点击侧边栏"文件管理"，主内容区展示 **文件资源库（网格视图 + 列表视图切换）**。

- **顶部筛选栏**：
  - 文件类型筛选：全部 / 图片 / 视频 / 文档（PDF/Word/Excel）。
  - 上传时间排序。
  - 搜索框：按文件名 / 上传者昵称检索。
- **文件列表（网格卡片视图，4列）**：
  - 每个文件卡片显示：文件缩略图（视频显示首帧，文档显示图标）、文件名、文件大小、上传者、上传时间。
  - **操作栏（悬停浮现）**：
    - 【预览】— 弹窗预览文件内容（图片/视频直接播放，文档在线预览）。
    - 【查询】— 弹出文件详情窗，显示 MD5 值、存储路径、上传 IP、关联内容 ID（如有）。
    - 【删除】— 二次确认后永久删除文件（同时清除所有关联引用）。
- **存储统计**：顶部显示"总存储用量 / 已用 X GB / 剩余 X GB"进度条，超出阈值时黄色预警。

---

### 7. 公报（系统消息）
**交互逻辑**：点击侧边栏"公报"，主内容区展示 **消息发送中心 + 历史记录**。

- **顶部：新建公报表单**：
  - **发送范围**（单选/多选）：
    - 【全体用户】— 向全平台所有用户发送系统通知。
    - 【指定用户】— 输入用户名/ID，支持多选（弹窗搜索选择）。
    - 【指定社区】— 选择目标社区，向该社区所有成员发送通知。
  - **消息标题**（必填，最多 30 字）。
  - **消息内容**（必填，富文本编辑器，支持插入链接和图片）。
  - **消息类型**：公告 / 警告 / 活动推广（不同类型展示不同颜色标签）。
  - **发送按钮**：点击后弹出确认框，确认后立即推送（WebSocket 实时下发），所有在线用户即时收到系统消息弹窗。
  - **历史记录列表**（按时间倒序）：
    - 显示：发送时间、发送范围（全体/个体/社区）、消息标题、发送人、状态（✅ 已送达 X 人）。
    - 支持【撤回】操作（5 分钟内发送的消息可撤回，撤回后用户端消息消失并显示"该消息已被撤回"）。

## 四、 全局补充规范（管理端专有）

| 项目 | 说明 |
|------|------|
| **权限分级** | 管理后台支持多角色（超级管理员 / 内容审核员 / 用户管理员），不同角色可见不同功能模块。 |
| **操作日志** | 所有管理操作（封禁、删除、审核、发送公报）自动记录日志，含操作人、操作时间、IP、操作对象。超管可查看完整日志。 |
| **二次确认** | 所有不可逆操作（删除用户、解散社区、永久删除文件）必须弹出二次确认弹窗，并要求输入操作原因。 |
| **数据刷新** | 在线人数、待审核数量等实时数据通过 WebSocket 推送，无需手动刷新页面。 |
| **快捷跳转** | 用户端任一内容详情页，管理员可点击"管理"按钮直接跳转至管理后台对应审核页面。 |
| **响应式适配** | 管理端以 PC 为主，表格视图支持横向滚动，确保宽屏下信息完整展示。 |

## 五、 管理端与用户端的联动关系

| 管理端操作 | 用户端影响 |
|------------|------------|
| 审核通过内容 | 内容在用户端主页/频道中正常展示。 |
| 审核驳回内容 | 内容在用户端显示"审核未通过"状态，仅作者可见。 |
| 封禁用户 | 该用户无法登录，已发布内容全部隐藏。 |
| 删除内容 | 该内容从用户端全平台移除，所有收藏/点赞数据清除。 |
| 发送公报（全体） | 用户端顶部出现系统通知横幅，点击可查看详情。 |
| 封禁社区 | 用户端该社区入口消失，成员收到系统通知。 |
| 解散会话 | 用户端会话列表移除该会话，成员收到系统通知。 |
