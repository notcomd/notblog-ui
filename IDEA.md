notblog-ui is a lightweight, opinionated UI toolkit for building personal blogs without a full CMS.

- Provide a set of accessible, themeable React components for posts, tags, and author pages.
- Offer a simple content model using Markdown with graymatter, avoiding complex data layers.
- Include a built-in search and filter system that works entirely client-side.
- Ship with two complete example blog themes to demonstrate customization.
- Keep the bundle under 30KB gzipped for fast static deployments.
